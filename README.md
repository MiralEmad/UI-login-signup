# Flutter Login & Signup UI 🥕📱

A simple and clean **Login & Signup UI** built with Flutter.

## ✨ Features

### 🔐 Login & Signup

* Separate Login and Signup screens.
* Navigation between Login and Signup screens.
* Clean and simple user interface.

### 🎨 Interactive Text Fields

* Text fields change their color when they are focused.
* The focused field uses a **green color** to match the app's theme.
* Password fields include a visibility icon to show or hide the password.

### ✅ Form Validation

* Email validation is implemented on both **Login** and **Signup** screens.
* Password validation is implemented on both screens.
* Validation messages appear when the entered data is invalid.

### ⌨️ Keyboard Handling

* The keyboard automatically disappears when the user taps anywhere outside the text fields.
* This provides a cleaner and smoother user experience.

## 🛠️ Technologies Used

* **Flutter**
* **Dart**
* **VS Code**
* **Android Emulator**

## 📱 Screens

### Login Screen

The Login screen contains:

* Email field
* Password field
* Forgot Password option
* Login button
* Navigation to Signup

### Signup Screen

The Signup screen contains:

* Username field
* Email field
* Password field
* Terms of Service and Privacy Policy
* Sign Up button
* Navigation to Login

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone YOUR_REPOSITORY_LINK
```

### 2. Open the project

Open the project folder in VS Code.

### 3. Get dependencies

```bash
flutter pub get
```

### 4. Run the application

```bash
flutter run
```

This project was created to practice building Flutter user interfaces, handling text input, form validation, navigation, password visibility, and keyboard interaction.
